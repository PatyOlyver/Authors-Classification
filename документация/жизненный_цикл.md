 # Жизненный цикл решения

1. Сбор данных
   - Тексты 6 авторов (WriterExtnd)
   - Тайные тексты (author1–author21)

2. Предобработка
   - Очистка текста
   - Разбиение на фрагменты (400 слов, overlap 50)

3. Извлечение признаков
   - TF-IDF (max_features=10000, ngram_range=(1,3))

4. Обучение моделей
   - Logistic Regression
   - SVM Linear
   - Random Forest

5. Ансамбль
   - Voting Classifier (majority voting)

6. Оценка
   - Accuracy
   - Cross-validation (5 folds)
   - Матрица ошибок

7. Деплой
   - Python-скрипт
   - requirements.txt

8. Мониторинг и диагностика
   - Отслеживание метрик
   - Проверка дисбаланса классов
