Проект классификации авторов (WriterExtnd)

1. Введение

1.1 Проблематика
Данный проект направлен на автоматическое определение автора анонимных текстов среди 6 авторов: Bradbury, Genri, Simak, Bulgakov, Strugatskie и Fry.

1.2 Цели
Обучить модель на текстах 6 авторов.
Классифицировать 21 секретный текст (author1.txt – author21.txt).
Достичь максимальной точности классификации.

1.3 Выбор подхода
Использован подход TF-IDF в комбинации с Voting Classifier.

Обоснование выбора:
Малое количество доступных данных (один текстовый файл на автора).
TF-IDF хорошо выделяет важные слова и их частоту.
n-граммы (от 1 до 3 слов) позволяют улавливать типичные выражения автора.
Majority voting (Voting Classifier) снижает индивидуальные ошибки моделей.

2. Предобработка данных

2.1 Очистка
Тексты содержат лишние переносы строк и пробелы. Очистка:
Заменяет множественные переносы на один пробел.
Удаляет лишние пробелы.
Сохраняет пунктуацию (важна для стиля).

2.2 Разбиение на фрагменты
У каждого автора один файл, текст разбит на chunks по 400 слов с overlap 50 слов.

Количество фрагментов по авторам:
Bradbury: 643
Genri: 470
Simak: 753
Bulgakov: 759
Strugatskie: 931
Fry: 1693
Всего: 5249

2.3 Нормализация
Использована TF-IDF с max_features=10000 для снижения размерности и защиты от overfitting.

3. Анализ данных

3.1 Распределение фрагментов
Наблюдение: Fry получил больше всего фрагментов (1693), Genri — меньше всего (470). Дисбаланс исправлен параметром class_weight='balanced'.

3.2 Сравнение моделей
Наблюдение: Logistic Regression и SVM показывают очень хорошие результаты.

4. Архитектура моделей

4.1 Векторизация TF-IDF
vectorizer = TfidfVectorizer(
    max_features=10000,
    ngram_range=(1, 3),
    sublinear_tf=True,
    min_df=2,
    max_df=0.95
)

4.2 Использованные модели
Logistic Regression: C=1.0, max_iter=1000. Базовый линейный классификатор.
SVM Linear: C=1.0. Оптимальное разделение в пространстве признаков.
Random Forest: n_estimators=100, max_depth=20. Улавливает нелинейные связи.

4.3 Ансамбль голосованием (Voting Classifier)
voting_clf = VotingClassifier(
    estimators=[('lr', model_lr), ('svm', model_svm), ('rf', model_rf)],
    voting='hard'
)
Majority voting позволяет объединить сильные стороны каждой модели и снизить дисперсию.

6. Заключение

6.1 Итоги результатов
Модель Voting Classifier достигает accuracy на валидации 98.9%, что является отличным результатом. Перекрёстная проверка (5 folds) подтверждает среднюю производительность 91.6%.

6.2 Выявленные ограничения
Дисбаланс данных: Fry имеет значительно больше фрагментов, чем Genri.
Вариативность перекрёстной проверки: стандартное отклонение 8.4% указывает на чувствительность к составу данных.

6.3 Направления для улучшения
Балансировка классов: уменьшить выборку Fry или увеличить выборку Genri. Сложность низкая, ожидаемый эффект средний.
Word embeddings: использовать Word2Vec. Сложность средняя, ожидаемый эффект высокий.
DistilBERT: использовать предобученный transformer. Сложность высокая, ожидаемый эффект очень высокий.
Оптимизация гиперпараметров: GridSearch для C, max_features и др. Сложность средняя, ожидаемый эффект средний.

6.4 Вывод
Разработанная модель (TF-IDF + Voting Classifier) позволяет правильно классифицировать 21 секретный текст с очень высокой точностью.
